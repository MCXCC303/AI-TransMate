## 安装

```shell
# 创建虚拟环境
python -m venv .venv
source .venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

## 使用

```shell
python main.py
```

首次运行会引导完成配置（API 提供商、密钥、目标语言）。
